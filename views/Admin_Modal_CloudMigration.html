นำเข้าข้อมูลจริงจาก Google Sheets สู่ Cloud SQL
แนะนำและเสถียรที่สุด วิธีที่ 1: นำเข้าผ่านไฟล์ Excel (.xlsx) ที่ดาวน์โหลดจาก Google Sheets
1. ใน Google Sheets เดิม: ไปที่เมนู ไฟล์ (File) > ดาวน์โหลด (Download) > Microsoft Excel (.xlsx)
2. คลิกปุ่มด้านล่างนี้แล้วเลือกไฟล์ Excel ที่เพิ่งดาวน์โหลดมา ระบบจะอ่านรายชื่อครูและประวัติการลาทั้งหมดเข้าสู่ SQL ทันที 100%
หรือ วิธีที่ 2: ดึงข้อมูลผ่าน URL ของ Google Apps Script
หาก Web App เปิดสิทธิ์การเข้าถึงแบบ "ทุกคน" (Anyone) เรียบร้อยแล้ว
