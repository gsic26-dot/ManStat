บันทึกการลาย้อนหลัง

บันทึกข้อมูลการลาย้อนหลังเข้าสู่ระบบ รองรับทั้งการบันทึกรายบุคคลและการจัดคิวแบบกลุ่ม (Batch Queue)
คำนวณอัตโนมัติ (แก้ไขได้)
ยังไม่ได้เลือกไฟล์ (.pdf, .jpg, .png)
ตารางคิวบันทึกแบบกลุ่ม (Staging Queue): รายการที่เพิ่มเข้าคิวจะยังไม่ถูกบันทึกจริงจนกว่าจะกดปุ่ม "ยืนยันบันทึกทั้งหมดลงฐานข้อมูล"
จำนวนในคิว: 0 รายการ
ลำดับ ชื่อ-สกุล ประเภทการลา ช่วงวันที่ วันทำการ โหมดอนุมัติ เหตุผลย้อนหลัง จัดการ
ยังไม่มีรายการในคิว กดเลือกแท็บ "บันทึกรายบุคคล" แล้วคลิกปุ่ม "+ เพิ่มเข้าคิวแบบกลุ่ม"

ประวัติการลาย้อนหลังในระบบ 0
