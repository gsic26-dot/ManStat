เกี่ยวกับระบบ (About ManStat): ความเป็นมาและวัตถุประสงค์ในการปฏิรูประบบสารสนเทศสถิติการลาและทะเบียนประวัติครู สำหรับสถานศึกษาขั้นพื้นฐาน (โรงเรียนชุมชนบ้านตะขบ สพป.นครราชสีมา เขต 3)
คุณสมบัติเด่นและโมดูลการทำงาน (Key Features):
📊 สถิติการลา & แดชบอร์ด: Real-time Quota, Multi-Filter, แถบสี Progress Bar, กราฟสถิติภาพรวม
📝 ยื่นคำร้อง & กระบวนการอนุมัติ: คำนวณวันลาทำการอัตโนมัติ (หักวันหยุดนักขัตฤกษ์), ครูสอนแทน, ลำดับขั้นการอนุมัติ 4 ขั้น, การมอบหมายผู้ลงนามแทน
🖨️ พิมพ์ใบลาทางการ: รูปแบบราชการถูกต้องตามระเบียบสำนักนายกรัฐมนตรีฯ พ.ศ. 2555 และแบบขออนุญาต 3 ชม.

แนวคิดการออกแบบ (UI/UX Design Philosophy): Steam Dark Theme Palette (#66c0f4, #a4d007, #d29922, #f85149, #171a21) และ Unified Stroke SVG Icons
โครงสร้างสถาปัตยกรรมและไฟล์ในโปรเจกต์ (Project Structure): จำแนกหมวดหมู่ Backend (GAS) และ Frontend (HTML/JS)
โครงสร้างฐานข้อมูล (Data Model): รายละเอียดของแต่ละ Sheet ใน Google Sheets
คู่มือการติดตั้ง (Quick Start): ขั้นตอนการติดตั้งผ่าน Google Clasp CLI และการตั้งค่า Deploy Web App
ระบบความปลอดภัย (Security): เข้ารหัสผ่านด้วย SHA-256 + Salt, สิทธิ์การใช้งาน 3 ระดับ (Superuser, Admin, User) และ Concurrency Lock
