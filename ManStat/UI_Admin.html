2.1 เพิ่มบัญชีผู้ใช้งานระบบ (สร้างรหัส EXE / TCH / STF ตามสายงานอัตโนมัติ)

กำหนดผู้รักษาราชการแทน (สายอนุมัติขั้นที่ 3)

มีสิทธิ์กดอนุมัติใบลาและปรากฏชื่อในแบบฟอร์มราชการ A4 เมื่อเปลี่ยนผู้ลงนาม

2.2 เลือกบุคลากรเพื่อแก้ไขข้อมูลละเอียด / โควตาวันลา

โควตาวันลาสูงสุดประจำปีงบประมาณ (วัน)

2.3 ตั้งค่าข้อมูลสถานศึกษา (School Profile)

ข้อมูลส่วนนี้จะถูกนำไปแสดงบนหัวตารางแดชบอร์ดและเอกสารรายงานใบลา A4 อัตโนมัติ
ตราสัญลักษณ์โรงเรียน
ไม่มีรูปภาพ
ข้อมูลพื้นฐานสถานศึกษาและผู้บริหาร
ข้อมูลการติดต่อและพิกัดภูมิศาสตร์ (GPS)

2.4 ระบบประกาศวันหยุดราชการ / วันหยุดพิเศษ

วันหยุดที่ประกาศในหน้านี้จะถูกนำไปตัดออกจากจำนวนวันทำการเวลาบุคลากรยื่นใบลาให้อัตโนมัติ
