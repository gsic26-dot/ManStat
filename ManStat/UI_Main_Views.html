ยื่นคำร้องขอลา / ขออนุญาตออกนอกบริเวณสถานศึกษา

กรอกข้อมูลคำร้องและเลือกผู้สอนแทนตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยการลา
 ระเบียบการลาพักผ่อนของข้าราชการครู
 ระเบียบการลาของผู้บริหารสถานศึกษา: ผู้อำนวยการสถานศึกษาไม่มีสิทธิยื่นลาและอนุมัติตนเองภายในสถานศึกษา ต้องยื่นใบลาต่อ ผู้อำนวยการสำนักงานเขตพื้นที่การศึกษา (สพป.) เท่านั้น

 รายการคำร้อง

รหัสคำร้อง ผู้ยื่นคำร้อง ประเภท ช่วงวันที่ / เวลา รวมเวลา ผู้สอนแทน สถานะ

 ติดตามคำร้อง

รหัสคำร้อง ผู้ยื่นคำร้อง ประเภท ช่วงเวลา การอนุมัติ พิมพ์เอกสาร

 แผนผังการบริหารงาน (Organization Chart)

โครงสร้างการบริหารงาน สายการบังคับบัญชา และการมอบหมายงานตามฝ่ายของสถานศึกษา • โรงเรียนชุมชนบ้านตะขบ (ปีการศึกษา 2569)

 ภาระงานของบุคลากร (Staff Workload Management)

ตรวจสอบและบริหารภาระงานประจำฝ่าย งานสอน และหน้าที่พิเศษของบุคลากรรายบุคคล
บุคลากรทั้งหมด 0
รายการภาระงานที่บันทึก 0
งานฝ่ายที่ยังไม่มีผู้รับผิดชอบ 0

 วิทยฐานะ

รหัส ชื่อ-นามสกุล วันที่บรรจุ วิทยฐานะ วันที่มีผล เลขที่คำสั่ง ก.พ. 7 ย่อ

 วุฒิลูกเสือ

รหัส ชื่อ-นามสกุล วุฒิทางลูกเสือ ประเภทกองลูกเสือ เลขที่วุฒิบัตร วันที่ได้รับวุฒิ

 ทะเบียนใบอนุญาตประกอบวิชาชีพและเอกสารรับรอง

ตรวจสอบข้อมูลและประวัติใบอนุญาตประกอบวิชาชีพครู ผู้บริหาร และเอกสารรับรอง แยกตามรหัสเฉพาะ

 แจ้งปรับปรุงระบบ

วันที่แจ้ง ผู้เสนอแนะ ประเภท หัวข้อและรายละเอียด สถานะ การแจ้งผล / จัดการ
 กราฟสถิติ & รายงานสรุปสำหรับผู้บริหารสถานศึกษา
 สัดส่วนจำนวนครั้งการลาแยกตามประเภท
 สถิติวันลาป่วย/ลากิจสะสมรายบุคคล (10 อันดับแรก)
 ตารางแผนอัตรากำลังและกำหนดการเกษียณอายุราชการของบุคลากร (เรียงตามปีเกษียณ)
รหัส ชื่อ-นามสกุล ตำแหน่ง วันเกิด อายุปัจจุบัน วันเกษียณ เวลาคงเหลือ
