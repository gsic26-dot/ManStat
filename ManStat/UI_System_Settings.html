โมดูลตั้งค่าระบบและจัดการทะเบียนบุคลากร (System & Registry Management)

ทะเบียนประวัติบุคลากร (บันทึกแยกทุกรายการ และคำนวณรายการสูงสุดอัตโนมัติ)
ข้อมูลที่บันทึกในส่วนนี้จะถูกส่งไปแสดงผลในเมนู ข้อมูลวิทยฐานะ, ข้อมูลวุฒิลูกเสือ, และ ข้อมูลใบอนุญาต ทางด้านซ้ายมือทันที

+ 1. บันทึกประวัติวิทยฐานะ (แยกจากวันบรรจุ)

+ 2. บันทึกประวัติวุฒิการศึกษา

+ 3. บันทึกประวัติวุฒิทางลูกเสือ

+ 4. บันทึกข้อมูลใบอนุญาตประกอบวิชาชีพ

+ เพิ่มบุคลากรใหม่ (สร้างรหัส EXE / TCH / STF อัตโนมัติ)

รายการผู้ใช้ทั้งหมดในระบบ (All Users Directory)

รหัส ชื่อ-นามสกุล ตำแหน่ง กลุ่มสาระ / แผนก สิทธิ์ระบบ สถานะ จัดการผู้ใช้

กำหนดผู้รักษาราชการแทน (สายอนุมัติขั้นที่ 3)

มีสิทธิ์กดอนุมัติใบลาและปรากฏชื่อในแบบฟอร์มราชการ A4 เมื่อเปลี่ยนผู้ลงนาม

ตั้งค่าข้อมูลผู้ใช้รายบุคคล & กำหนดระดับสิทธิ์ User

โควตาวันลาสูงสุดประจำปีของข้าราชการครู (ไม่มีลาพักผ่อน)

ตั้งค่าข้อมูลสถานศึกษา (School Profile)

สร้างประกาศวันหยุดใหม่

รายการวันหยุดที่ประกาศในระบบ
