แบบฟอร์มยื่นใบลาออนไลน์ / ขออนุญาตออกนอกสถานศึกษา (ไม่เกิน 3 ชั่วโมง)

ระบบคำนวณเฉพาะวันทำการ (ตัดวันเสาร์-อาทิตย์ และวันหยุดราชการที่ประกาศไว้โดยอัตโนมัติ)
* การขออนุญาตออกนอกสถานศึกษา ระบบจำกัดเวลาไม่เกิน 3 ชั่วโมง

ทะเบียนประวัติบุคลากร (บันทึกแยกทุกรายการ และคำนวณรายการสูงสุดอัตโนมัติ)

วันที่บรรจุและวันที่ได้รับวิทยฐานะแยกออกจากกัน โดยระบบจะดึงระดับสูงสุดไปแสดงบนหน้าหลัก

1. เพิ่มประวัติการได้รับวิทยฐานะ

2. เพิ่มประวัติวุฒิการศึกษา

3. เพิ่มประวัติวุฒิทางลูกเสือ

4. เพิ่มข้อมูลใบอนุญาตประกอบวิชาชีพ
