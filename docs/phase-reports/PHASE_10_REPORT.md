## 1. วัตถุประสงค์และขอบเขตงาน (Scope & Objectives)

Phase 10 คือเฟสปิดจบการเชื่อมโยงระบบบริหารงานบุคลากรและวิชาการทั้งหมดของ **ManStat-Modern (โรงเรียนชุมชนบ้านตะขบ)** ให้เชื่อมต่อกันเป็นหนึ่งเดียว โดยไม่ต้องเพิ่มเมนูใน Sidebar และไม่ต้องเพิ่มตารางฐานข้อมูลใหม่:

1. **Pure PA & OBEC Directory Aggregation Engine (`pa-summary-utils.ts`):**
   - สร้างฟังก์ชันคำนวณบริสุทธิ์ (`buildObecSystemDirectory`, `buildPaStaffSummary`) และตัวส่งออกไฟล์ CSV มาตรฐาน RFC-4180 พร้อม UTF-8 BOM (`\uFEFF`) สำหรับเปิดใน Microsoft Excel ภาษาไทยได้ทันทีโดยไม่เพี้ยน (`exportObecDirectoryCsv`, `exportPaSummaryCsv`)
2. **Live 4-Division Org Chart Sync (`ViewOrgChart.tsx`):**
   - เพิ่มตัวเลือก **`ปีการศึกษา`** ในส่วนหัวของผังโครงสร้างองค์กร
   - ซิงก์รายชื่อหัวหน้ากลุ่มบริหารงาน (`หัวหน้าฝ่าย` / `หัวหน้ากลุ่มบริหาร`), สมาชิกทั้งหมด, ตำแหน่งหน้าที่ (`roleTitle`) และจำนวนระบบรายงาน สพฐ. จากตาราง `staff_workloads` แบบเรียลไทม์ พร้อมแสดงชื่อเต็มบุคลากรแบบสะอาดไม่มีวงเล็บตำแหน่งต่อท้าย
3. **3-in-1 Executive Workload Suite (`ViewWorkload.tsx` + `PaReportPrintView.tsx`):**
   - เพิ่มแท็บย่อย 3 แท็บด้านบนในเมนู `ภาระงาน` ได้แก่:
     1. **`รายการภาระงาน`**: คงการทำงานเดิมของ Phase 8 / 8.1 (งาน 4 ฝ่าย, Cascading 2 ขั้น, คัดลอกข้ามปีการศึกษา) ไว้ครบถ้วน 100%
     2. **`ทำเนียบระบบ สพฐ. (38 ระบบ)`**: แสดงแถบ KPI ความครอบคลุม (`มอบหมายแล้ว X / 38 ระบบ`), ค้นหาและกรองตามฝ่าย/สถานะ, ส่งออก CSV, พิมพ์ A4 แนวนอน และปุ่ม **`มอบหมายทันที`** 1 คลิกสำหรับแอดมินบนระบบที่ยังไม่มีผู้รับผิดชอบ (เปิด Modal เดิมพร้อมตั้งค่าฝ่ายและรหัสระบบให้อัตโนมัติ)
     3. **`สรุปภาระงานรวม (PA)`**: รวมข้อมูลชั่วโมงสอน (`ป.1–ม.3` + `อ.1–อ.3` ปฐมวัย), เกณฑ์ ก.ค.ศ. ว 9/2564, ชั่วโมงสอนแทนสะสมรายภาคเรียน, ฝ่ายงาน, งานบริหาร/โครงการ และระบบ สพฐ. ของบุคลากรทุกคน พร้อม KPI 4 การ์ด, ส่งออก CSV (`ManStat_PA_Summary_<year>_<semester>.csv`) และพิมพ์สรุป PA (A4 แนวนอน)

## 3. รายละเอียดเชิงเทคนิคและมาตรฐานที่ยึดถือ (Technical Standards)

- **Zero-Emoji UI Standard:** ใช้เฉพาะไอคอนเวกเตอร์ Lucide SVG ไม่มีอีโมจิใน UI หรือข้อความแจ้งเตือน รองรับ Light/Dark Mode และใช้เลขอารบิก (`0-9`)
- **Modern Web Guidance (Responsive Tables & Forms):** ตารางทำเนียบ 38 ระบบ สพฐ. และตารางสรุป PA ใช้ `overflow-x-auto` ร่วมกับ `tabIndex={0} role="region"` เพื่อให้เลื่อนแนวนอนด้วยคีย์บอร์ดได้, ใช้ `whitespace-nowrap` บนคอลัมน์ชื่อ-สกุล และคง Close-Lock บน Modal ฟอร์มทั้งหมด
- **Database Reuse (Zero New Migrations):** ดึงข้อมูลผ่าน API ที่มีอยู่แล้วทั้งหมด (`/api/admin/staff`, `/api/admin/workload`, `/api/timetable`, `/api/timetable/substitutions`) โดยไม่แก้ไข Schema ฐานข้อมูล
- **Neutral Non-Teaching Classification:** บุคลากรสายสนับสนุน/บริการ (เช่น นักการภารโรง) ที่ไม่มีภาระงานสอนจะแสดงสถานะ `'สายสนับสนุน / บริการ'` อย่างชัดเจน ไม่ถูกนับเป็นครูต่ำกว่าเกณฑ์ ว 9/2564

## 5. แนวทางการใช้งานสำหรับผู้ดูแลระบบและผู้บริหาร (Operational Guide)

1. **ผังโครงสร้างองค์กร (`โครงสร้างองค์กร`):** เลือกปีการศึกษาที่มุมขวาบนเพื่อดูรายชื่อหัวหน้าฝ่าย บุคลากรในแต่ละฝ่าย ป้ายหน้าที่รับผิดชอบ และจำนวนระบบ สพฐ. ที่ซิงก์ตรงจากข้อมูลภาระงาน
2. **ตรวจสอบความครอบคลุม 38 ระบบ สพฐ. (`ภาระงาน` -> แท็บ `ทำเนียบระบบ สพฐ. (38 ระบบ)`):** กรองดูเฉพาะรายการที่ `ยังไม่มีผู้รับผิดชอบ` แล้วกดปุ่ม `มอบหมายทันที` เพื่อเปิดฟอร์มมอบหมายงานที่เลือกฝ่ายและรหัสระบบให้พร้อมใช้งานทันที หรือกด `ส่งออก CSV (Excel)` / `พิมพ์ A4`
3. **สรุปภาระงานรวมเพื่อประเมิน PA (`ภาระงาน` -> แท็บ `สรุปภาระงานรวม (PA)`):** เลือกปีการศึกษาและภาคเรียน (`ภาคเรียนที่ 1` / `ภาคเรียนที่ 2`) ระบบจะรวมชั่วโมงสอน ป.1–ม.3, ปฐมวัย อ.1–อ.3, ชั่วโมงสอนแทนสะสม, งาน 4 ฝ่าย และระบบ สพฐ. พร้อมส่งออกไฟล์ Excel CSV หรือสั่งพิมพ์กระดาษ A4 แนวนอนเสนอผู้อำนวยการลงนามได้ทันที

## 6. ข้อควรทราบ (Notes)

- การส่งออก CSV ใช้รหัสอักขระ UTF-8 with BOM (`\uFEFF`) และ Escaping ตามมาตรฐาน RFC-4180 ทำให้เปิดด้วย Microsoft Excel บน Windows ได้ทันทีโดยภาษาไทยไม่เพี้ยน
- การสั่งพิมพ์ A4 แนวนอน (`PaReportPrintView`) ถูกออกแบบให้ซ่อนเมนูระบบและแถบเครื่องมือโดยอัตโนมัติขณะสั่งพิมพ์ผ่าน `@media print`
