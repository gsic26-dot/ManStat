## 3. สรุปการแก้ไขจริง (Exact Changes Made)

### 3.1 การตัดวงเล็บซ้ำซ้อนและทำให้ป้ายชื่อกระชับ
- **รายชื่อบุคลากรในฟอร์ม (`ViewWorkload.tsx`):** แสดงเฉพาะชื่อ-สกุลเต็ม (`คำนำหน้า + ชื่อจริง นามสกุล`) ทั้งในดรอปดาวน์ `บุคลากรผู้รับผิดชอบหลัก *` และรายการเลือก `ผู้ร่วมรับผิดชอบ` โดยตัดวงเล็บตำแหน่งต่อท้ายออกทั้งหมด
- **ชื่อตำแหน่งงานมาตรฐาน 4 ฝ่าย (`obec-admin-roles.ts`):** ตัดวงเล็บตัวย่อระบบที่ซ้ำซ้อนกับป้าย `obecSystems` ออกครบ 5 รายการ:
  - `งานประกันคุณภาพการศึกษาภายใน (SAR / สมศ.)` → `งานประกันคุณภาพการศึกษาภายใน`
  - `งานทดสอบระดับชาติ (RT / NT / O-NET)` → `งานทดสอบระดับชาติ`
  - `งานวิทยฐานะและการประเมินผลการปฏิบัติงาน (PA / DPA)` → `งานวิทยฐานะและการประเมินผลการปฏิบัติงาน`
  - `งานสารสนเทศ ข้อมูลนักเรียนรายบุคคล และเทคโนโลยี (ICT)` → `งานสารสนเทศ ข้อมูลนักเรียนรายบุคคล และเทคโนโลยี`
  - `งานคุณธรรมและความโปร่งใสในสถานศึกษา (ITA)` → `งานคุณธรรมและความโปร่งใสในสถานศึกษา`
  - คงป้ายระบบรายงาน สพฐ. (`obecSystems`) ทั้ง 38 ระบบครบถ้วน 100%
- **ป้ายชื่อฟอร์ม (`ViewWorkload.tsx`):** ปรับเป็นภาษาไทยที่กระชับ เช่น `ขอบข่ายภาระงาน`, `ผู้ร่วมรับผิดชอบ`, `สังกัดฝ่ายงาน`, `งานบริหารและงานประจำฝ่าย`

### 3.2 ปรับฟอร์มเป็น Cascading 2 ขั้น (`สังกัดฝ่ายงาน` → `ตำแหน่ง/หน้าที่รับผิดชอบ` → เติมข้อมูลอัตโนมัติ)
- ลบกล่องเลือกแม่แบบด้านบนที่ซ้ำซ้อนออก และปรับลำดับฟอร์มใน `ViewWorkload.tsx` เป็น:
  1. **แถวที่ 1:** `บุคลากรผู้รับผิดชอบหลัก *` + `ปีการศึกษา *`
  2. **แถวที่ 2:** `ประเภทภาระงาน *` (`งานบริหารและงานประจำฝ่าย` หรือ `งานโครงการและคณะกรรมการเฉพาะกิจ`)
  3. **แถวที่ 3 (Cascading 2 ขั้น):**
     - **ประเภทงานบริหารและงานประจำฝ่าย:** ช่องซ้ายเลือก `สังกัดฝ่ายงาน *` (4 ฝ่ายมาตรฐาน สพฐ.) → ช่องขวากรอง `ตำแหน่ง / หน้าที่รับผิดชอบ *` เฉพาะตำแหน่งของฝ่ายที่เลือก พร้อมตัวเลือกสุดท้าย `+ ระบุตำแหน่ง / หน้าที่เอง...` ที่เปิดช่องพิมพ์เองด้านล่างเมื่อเลือก
     - **ประเภทงานโครงการและคณะกรรมการเฉพาะกิจ:** ดรอปดาวน์ `ชื่อโครงการ / คณะกรรมการ *` (7 แม่แบบ + `+ ระบุชื่อโครงการ / คณะกรรมการเอง...`)
  4. **Auto-Fill & Edit Preservation:** เมื่อเลือกตำแหน่งมาตรฐานจากดรอปดาวน์ ระบบเติม `ขอบข่ายภาระงาน` (พร้อมป้าย `เติมข้อมูลอัตโนมัติ`), `บทบาทในงาน` และเลือกป้าย `ระบบรายงาน สพฐ.` ให้อัตโนมัติ โดยยังแก้ไขได้อิสระ และเมื่อเปิดโหมดแก้ไขรายการเดิมจะคงข้อมูลที่บันทึกไว้เดิมทุกช่องไม่เขียนทับจนกว่าผู้ใช้จะเปลี่ยนตัวเลือกเอง
- **Modal Close Lock:** ล็อกทั้ง Modal มอบหมายงาน และ Modal คัดลอกโครงสร้างข้ามปี ไม่ให้ปิดเมื่อคลิกพื้นหลังหรือกด `Escape` (ปิดได้เฉพาะปุ่ม `X` หรือ `ยกเลิก`)

### 3.3 ระบบคัดลอกโครงสร้างงานข้ามปีการศึกษา (Smart Academic Year Rollover)
- **Pure Helper (`src/lib/regulations/workload-rollover.ts`):** สร้าง `buildRolloverWorkloads(params)`:
  - ไม่แก้ไขหรือลบข้อมูลปีต้นทาง (เก็บประวัติ PA/SAR ครบถ้วน)
  - คัดลอก `งานบริหารและงานประจำฝ่าย` เป็นค่าเริ่มต้น และเลือกคัดลอก `งานโครงการและคณะกรรมการเฉพาะกิจ` เพิ่มเติมได้; **ไม่คัดลอกรายการงานสอนเดิม (หมวด 1) เด็ดขาด**
  - คัดกรองเฉพาะบุคลากรที่ยังมีสถานะปฏิบัติงานในตารางบุคลากร และตัด `coResponsibleIds` ที่พ้นสภาพออกอัตโนมัติ
  - ล้าง `orderOrRef` เป็นค่าว่าง `''` และรีเซ็ต `status` เป็น `'กำลังดำเนินการ'`
  - ป้องกันข้อมูลซ้ำแบบ Idempotent (เทียบ `teacherId + category + normalizedDivision + normalizedTitle` ในปีปลายทาง) พร้อมส่งคืน `{ recordsToCreate, skippedDuplicates, skippedInactiveStaff }`
- **Server Persistence & API:** เพิ่ม `dbInsertWorkloadsBatch` ใน `src/lib/db/serverDb.ts` (รองรับทั้ง Supabase และ Local JSON Fallback) และสร้าง Endpoint `POST /api/admin/workload/rollover` (`src/app/api/admin/workload/rollover/route.ts`) ป้องกันด้วย `verifyAdminSession()` พร้อมบันทึก Audit Log (`ROLLOVER_WORKLOAD`)
- **UI Integration (`ViewWorkload.tsx`):** เพิ่มปุ่ม `คัดลอกโครงสร้างข้ามปี` บนแถบหัวหน้าจอ (Admin เท่านั้น) และแบนเนอร์ CTA เมื่อเลือกดูปีการศึกษาที่ยังไม่มีข้อมูล (เช่น `2570`) พร้อม Modal แสดงจำนวนรายการจริงจากปีต้นทาง เมื่อสำเร็จจะรีเฟรชข้อมูลและสลับตัวกรองไปยังปีปลายทางทันที
