## 3. สรุปการแก้ไขจริง (Exact Changes Made)

### 3.1 ปรับชื่อเมนู Sidebar ให้กระชับ & เพิ่มตำแหน่ง `งานการศึกษาปฐมวัย`
- **`src/app/page.tsx` (Desktop Sidebar & Mobile Drawer):**
  - `งานบริหาร 4 ฝ่ายและหน้าที่พิเศษ` → **`ภาระงาน`** (คง `activeView === 'workload'` และ `/?view=workload` ครบ 100%)
  - `ตารางสอนและชั่วโมงสอน` → **`ตารางสอน`** (คง `activeView === 'timetable'` และ `/?view=timetable` ครบ 100%)
- **`src/lib/regulations/obec-admin-roles.ts`:**
  - เพิ่มตำแหน่งมาตรฐาน `ACA-10` ภายใต้ `ฝ่ายบริหารวิชาการ`: **`งานการศึกษาปฐมวัย`** (ไม่มีวงเล็บซ้ำซ้อน) พร้อมขอบข่ายงานปฐมวัยและรหัสระบบ สพฐ. `['e-SAR', 'Q-Info']` ที่ผ่านการตรวจสอบกับ `OBEC_SYSTEM_CATALOG`

### 3.2 คัดกรองนักการภารโรงออกจากงานสอน & แยกป้ายผู้บริหารกับสายสนับสนุน (`timetable-utils.ts`)
- เพิ่มฟังก์ชัน **`isEligibleForTeaching(staff)`** คัดกรองตำแหน่งบริการ/ภารโรง (`นักการภารโรง`, `ภารโรง`, `พนักงานบริการ`, `ยาม`, `ลูกจ้างชั่วคราวภารโรง`) ออกจากดรอปดาวน์เลือกครูผู้สอน/ครูร่วมสอน/ครูประจำชั้นปฐมวัย/ผู้ช่วยทุกจุดใน `ViewTimetable.tsx` และจากตารางสรุป ว 9/2564 (โดยยังคงข้อมูลเดิมหากมีคาบเก่าผูกไว้อยู่)
- แยกป้ายสถานะใน `calculateTeacherWeeklyLoads(...)` (`w9StatusLabel`) ออกเป็น 4 สถานะชัดเจน:
  - **`ผู้บริหารสถานศึกษา`** (ผู้อำนวยการ / รองผู้อำนวยการ)
  - **`สายสนับสนุน`** (ธุรการ, พี่เลี้ยงเด็กพิการ ฯลฯ)
  - **`ผ่านเกณฑ์`** (`>= 12 ชม./สัปดาห์`) / **`ต่ำกว่าเกณฑ์`** (`< 12 ชม./สัปดาห์`)

### 3.3 เปลี่ยนคำศัพท์จาก "คาบ" เป็น "ชั่วโมง" ครบทั้งระบบ (Web UI & A4 Print)
- หัวคอลัมน์ตาราง 5×7 ทั้งใน `ViewTimetable.tsx` และ `TimetablePrintView.tsx`:
  - มุมบนซ้าย: **`วัน / ชั่วโมง`**
  - ช่อง 1–6: **`ชั่วโมงที่ 1`** ถึง **`ชั่วโมงที่ 6`** (แปลง label เดิมจาก DB ที่ขึ้นต้นด้วย `คาบที่ ` ให้เป็น `ชั่วโมงที่ ` อัตโนมัติด้วย)
  - ช่อง 7 (`15.30 - 16.00`, 30 นาที = `0.5` ชม.): **`พบครูประจำชั้น`**
- ปุ่มและป้ายข้อความ: `ตั้งค่าเวลาเรียน`, `+ เพิ่มวิชา`, `สลับชั่วโมง`, `จัดตารางอัตโนมัติ`, `จำนวนชั่วโมง / สัปดาห์`, `ลงตารางแล้ว P/T ชม.`
- ตัวนับแผนการสอน: **`จัดสรรแล้ว X / 30 ชม.เรียน + ประจำชั้น Y ชม.`** (คำนวณ 5 ช่วงประจำชั้น = `2.5 ชม.`)
- แถบสรุปตารางสอนรายบุคคล (Web & Print): **`สอน X ชม./สัปดาห์`** (และ **`• พบครูประจำชั้น Y ชม.`** เมื่อมี)
- ตาราง `สรุปชั่วโมงสอน (ว 9/2564)`: เปลี่ยนคอลัมน์ `รวมคาบ` เป็น **`รวมทั้งหมด (ชม.)`**

### 3.4 ขัดเกลา Layout หน้าจอ `ViewTimetable.tsx`
- **แถบเครื่องมือตารางเรียนรายห้อง (1 แถวกระชับไม่ตกบรรทัด):** รวมปุ่มพิมพ์เป็นดรอปดาวน์ **`พิมพ์ A4 ▾`** (`พิมพ์ห้องนี้ A4` / `พิมพ์ทุกห้อง ป.1–ม.3 A4` ปิดอัตโนมัติเมื่อคลิกนอกกรอบ) คู่กับปุ่ม **`สลับชั่วโมง`** และ **`จัดตารางอัตโนมัติ`**
- **แก้ขอบตาราง 5×7 โดนตัดและหัวคอลัมน์พักกลางวัน:** ใช้ `table-fixed w-full min-w-[780px]`, ย่อความกว้างคอลัมน์ `วัน / ชั่วโมง` (`82px`) และคอลัมน์พักกลางวัน (`28px`), ลบข้อความ `พัก 11.30` ที่เบียดใน `<th>` ออกให้สะอาดตา (คงข้อความแนวตั้ง `พักกลางวัน (11.30 - 12.30)` กลางแถว `<tbody>`)
- **ป้ายแจ้งเตือนค่าเริ่มต้นแท็บปฐมวัย:** แสดงป้าย **`ตัวอย่างค่าเริ่มต้น (ยังไม่บันทึก)`** เมื่อห้อง `อ.1–อ.3` ยังไม่เคยบันทึกในฐานข้อมูล
- **ตารางสรุป ว 9/2564:** เพิ่มแถบสรุปด้านบน (**`ผ่านเกณฑ์ X คน`** • **`ต่ำกว่าเกณฑ์ Y คน`** • **`ผู้บริหารและสายสนับสนุน Z คน`**) และใส่ `whitespace-nowrap min-w-[180px]` ให้คอลัมน์ **`ชื่อ-สกุล`** ไม่ตัดบรรทัดกลางคำ

## 6. สิ่งที่ผู้ใช้ต้องดำเนินการเองและเช็กลิสต์ตรวจสอบ (Manual Steps & QA Checklist)
- **ไม่ต้องรัน SQL Migration เพิ่มเติม**
- **เช็กลิสต์ตรวจสอบบนหน้าเว็บจริง:**
  1. ตรวจ Sidebar ซ้าย (และ Mobile Drawer) แสดงชื่อเมนู **`ภาระงาน`** และ **`ตารางสอน`** กระชับไม่ล้นบรรทัด
  2. เปิดหน้า **`ภาระงาน`** (`/?view=workload`) → มอบหมายงาน → เลือก `ฝ่ายบริหารวิชาการ` → ตรวจว่ามี **`งานการศึกษาปฐมวัย`** ให้เลือกและเติมขอบข่าย + ระบบ `e-SAR`, `Q-Info` อัตโนมัติ
  3. เปิดหน้า **`ตารางสอน`** (`/?view=timetable`):
     - ตรวจว่าแถบเครื่องมือด้านขวาของตารางเรียนรายห้องอยู่ในแถวเดียว (`พิมพ์ A4 ▾`, `สลับชั่วโมง`, `จัดตารางอัตโนมัติ`) และตาราง 5×7 แสดงครบถึง `พบครูประจำชั้น (15.30 - 16.00)` โดยไม่โดนตัดขอบขวา
     - ตรวจว่าดรอปดาวน์เลือกครูทุกจุดไม่มี `นักการภารโรง` ปรากฏ
     - ตรวจแท็บ `ระดับปฐมวัย (อ.1–อ.3)` แสดงป้าย `ตัวอย่างค่าเริ่มต้น (ยังไม่บันทึก)` เมื่อยังไม่ได้บันทึก
     - ตรวจแท็บ `สรุปชั่วโมงสอน (ว 9/2564)` แสดงแถบสรุป 3 ป้ายด้านบน, คอลัมน์ `ชื่อ-สกุล` ไม่ตัดบรรทัดกลางคำ, คอลัมน์ `รวมทั้งหมด (ชม.)` และป้ายแยก `ผู้บริหารสถานศึกษา` กับ `สายสนับสนุน` ชัดเจน
